OrdoProche

Application d'ordonnances pour médecins

Politique de confidentialité

Version du 26 novembre 2026. Elle vaut pour l'application OrdoProche sur Android et sur Windows, et pour ce site.

OrdoProche n'envoie vos données à personne. Il n'y a ni compte à créer, ni serveur, ni publicité, ni mesure d'audience. Ce que vous saisissez reste dans votre appareil, dans une base chiffrée.

Qui répond de quoi

L'éditeur et vous

L'application est éditée par Jean Houël, médecin généraliste, en entreprise individuelle. Pour toute question : contact@ordoproche.fr.

L'éditeur n'a aucun accès à ce que vous enregistrez dans l'application. Pour les données de vos patients, vous êtes le responsable du traitement, comme pour votre dossier médical habituel.

Dans votre appareil

Ce que l'application enregistre

  • Votre profil : nom, numéro RPPS, coordonnées du cabinet, signature.
  • Vos patients : nom, prénom, sexe, date de naissance, poids, et si vous les saisissez téléphone, adresse et note pratique.
  • Vos documents : ordonnances, courriers, certificats et autres documents que vous rédigez ou importez.

Tout cela est rangé dans une base chiffrée, dont la clé est gardée par le système de l'appareil. L'application se verrouille par un code à six chiffres, avec l'empreinte en option. Elle est exclue de la sauvegarde automatique d'Android.

Le réseau

Quand l'application se connecte

L'application fonctionne sans connexion. Elle n'utilise le réseau que dans deux cas, toujours à votre demande.

  • Mettre à jour la liste des médicaments. Elle télécharge les fichiers publics de la base de données publique des médicaments (medicaments.gouv.fr). Rien n'est envoyé, hormis la demande de téléchargement elle-même.
  • Envoyer en direct et synchroniser. Le document passe par un Wi-Fi local, d'un appareil à l'autre, sans transiter par Internet.

Certains boutons ouvrent un site public dans votre navigateur, par exemple l'Annuaire Santé. Vous quittez alors l'application.

Les autres applications

Ce qui passe par votre téléphone

  • Partager ou imprimer. Le document est remis à l'application que vous choisissez (messagerie, imprimante). C'est elle qui l'achemine, selon ses propres règles.
  • Dicter. La dictée est celle de votre téléphone (Google ou Samsung). Si le français hors ligne n'y est pas installé, votre voix peut être envoyée à ce fournisseur. Ne dictez pas le nom d'un patient.
  • Lire une photo, un PDF ou un QR code. La lecture se fait dans l'appareil, avec un composant de Google (ML Kit). L'image n'est pas envoyée. Ce composant peut transmettre à Google des mesures techniques sur son fonctionnement, sans le contenu lu.

Le code d'activation

Les seules données que reçoit l'éditeur

Pour obtenir votre code, vous écrivez à l'éditeur par messagerie sécurisée en indiquant votre nom, votre numéro RPPS et votre adresse de messagerie. Ces informations servent à vérifier que vous êtes médecin et à établir un code à votre nom.

Elles sont conservées dans un registre tenu hors ligne, pendant la validité du code puis un an, avant d'être effacées. Le texte de votre demande est gardé trois mois. Elles ne sont ni cédées, ni utilisées à d'autres fins. Ce traitement repose sur l'intérêt légitime de réserver l'application aux médecins.

Vous pouvez demander à consulter, corriger ou effacer ces informations à contact@ordoproche.fr. Vous pouvez aussi saisir la CNIL (cnil.fr).

Garder ou effacer

Vous gardez la main

  • Sauvegarder. La sauvegarde est un fichier chiffré par une phrase secrète que vous choisissez. Vous décidez où le ranger.
  • Tout effacer. Dans Profil, « Sécurité et sauvegarde », l'effacement complet vide l'application. La désinstaller supprime aussi ses données.

Ce site

Pas de traceur

Ce site ne dépose aucun cookie et ne mesure pas son audience. Il est hébergé par GitHub, qui reçoit comme tout hébergeur l'adresse IP des visiteurs. La page d'accueil interroge GitHub pour afficher le numéro de la dernière version.
